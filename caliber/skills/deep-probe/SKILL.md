# 深度追问（deep-probe · caliber 融合版）

**防清单化声明**：本 skill 是对齐工艺不是提问模板。按清单机械问 = 审讯 = 失败。
每个问题必须由当前最大的不确定性驱动。每一问、对方每一次如何回应，都是对方
信号。

> 变更日志归工作仓 `docs/skills-changelog.md`（skill 文件不携带 changelog——log 只记工作仓，不进发布仓）。

## 道层（不可违反）

1. **追问为对齐不为表演**：每个问题必须压缩目标的某个真实不确定性。为显聪明而问、为凑流程而问 = 探针成瘾，浪费对方带宽。
2. **事实查环境，决策问对方**：环境里可查的事实（代码、文档、数据、既有记录）直接去查，不问对方；决策（要什么/不要什么/接受什么代价）永远交给对方，等答案再动。
3. **一次一问，问必显态**：一次只问一个问题；每个问题必须是二态之一——**采集问**（开放、禁带注，收对方的词汇与框架）或**押注问**（附你的建议答案，显式、可带置信度、可证伪，收裁决）。**禁止中间态**：带暗示的开放问兼具两者最差性质（污染采集、又无靶子可纠正）——锚定要么显式成注，要么不存在。选型规则见法层「双态引擎」。押错反而是资产——错误提案泄露的意图不比正确提案少。
4. **层级递进**：道层缺口（价值排序/不可妥协项/失败的形状）先于法层（机制/优先级裁决）先于术层（规格/工具）。目标还模糊就问实现细节 = 把未定型的目标冻死在实现里。
5. **停止条件显式**：共同理解的判据 = 你能从对方的一句话重推目标全貌，且对方认可这个重推。达成即收口，不恋战。收口不是沉默，是对齐快照交付。

## 档位协议

- **L 级 = 全仪式**：本文件全部协议（开局→追问循环→双轨方案探索→收口对齐
  快照）。
- **ML 级 = 轻量档双轨**：重述 + 方案探索协议全量（含挑战轨）+ **停**——重述
  目标一句话 → 挑战者后台派遣 + 主轨 2-3 方案 → 对照表 → 停在方案确认。
- **MS 级 = 轻量档单轨**：重述 + 方案探索协议主轨（不另派挑战者）+ **停**——
  重述目标一句话 → 2-3 方案各带取舍与推荐 → 停在方案确认。适用场景 = 子档
  已前置拍板 MS（如用户任务开始时声明）；caliber 常规流程中派遣发生在子档
  未定期间、一律按 ML 双轨执行，方案确认停止点拍板 MS 时挑战轨对照表照常
  展示，不追溯重派、不丢弃。
- **开创性档（ML/L 级可选分支）**：阶段 1 判定命中开创性信号（判定与
  降级出口见 references/frontier-protocol.md §定位与触发判定）时，方案探索段
  替换为**方案空间勘探漏斗**（空间图 → 环 1 → 组合式入选 → 同构展开 →
  环 2 → 融合审查 → 选择矩阵），对照表由选择矩阵替代；出口仍是方案确认停止点（**不新增停止点**）；
  时间维（挂起探索 / 阶段化承诺 / 重探索触发器）由 frontier-protocol §时间维承载。
- **S 级不经本 skill**（对话内直接解决）。

任务分级归 caliber Step 1，本 skill 不重复分类——三路径分类
（bounded/architectural/spike）不纳入的理由：定级已有唯一权威（caliber Step 1
+ 复量条款），双源定级必冲突。

## 法层

### 开局协议

模糊目标进来，第一动作不是提问：

0. **选择权让渡**（opt-out）：第一消息先给一行退出通道（「想跳过提问直接开工，
   说一声即可」）——对方接了，追问循环不再启动，按正常流程直接做；**边界**：
   opt-out 只跳过追问循环，不跳过方案确认/批准门（caliber 停止点照常）；
1. 用一句话重述你理解的目标（显影你的误读，让对方纠正最便宜）；
2. 指出你认为最关键的 1-2 个不确定性；
3. 第一问的形态由双态引擎的入口判定决定（看输入沉积物，不看猜测）。

对方带**半成形方案**来时：先切审计视角——读完全部材料，列出软肋与假设清单，
第一问从最大的未验证假设开始（不从零逼道）。

### 双态引擎（采集/押注的选型协议）

每轮选型是查表级操作，不许膨胀成第二重分析。管辖范围 = 开局协议与追问循环
（L 级全量；轻量档仅开局段——重述确认后直达方案探索，主循环不启动）。状态
四字段，可外化成两三行工作笔记（落点随手：快照草稿旁或台账行，无固定
schema——有即可，外化是助记不是交付）。对接 caliber 不确定性因子：
定级宣布的「最大未知」即天然首前沿。

```
前沿：<当前最大不确定性>  押注存活：近4注 x/4  成形度：未言|碎片|成段  带宽：正常|耗竭
```

- **成形度检测**：对方用自带词汇成段讲述、主动讲场景/时刻、说「我们的」、
  **纠正你的术语**（= 他在这话题的概念结构比你成形，最强成形度信号）；反向
  线索：hedging（「可能/差不多/随便」）、原样回声你的术语、「你定吧」。
- **入口判定**（看原料库存，不看猜测）：

| 开局输入形态 | 首动 |
|---|---|
| 一句话模糊目标（无场景无自带词汇） | 采集问（问时刻/场景） |
| 模糊目标但附原话段落（邮件/笔记/记录） | 回放押注（压缩其原话 + 「哪里错了」） |
| 半成形方案/文档 | 审计模式 → 最大未验证假设押注 |
| 明示「直接执行」/ 接了退出通道 | opt-out，直接做 |
| 续会话（有旧快照/旧 plan） | 回放押注旧快照——存库状态 = 待证伪的注册预测 |

- **主循环**（对方回应 → 三分类 → 查表）：

| 上轮是 | 结果 | 下一动 |
|---|---|---|
| 押注问 | 证实 | 存活+1 → 推进下一前沿（新子话题走入口判定微缩版） |
| 押注问 | 纠正（局部：机制替换/细节） | 吸收纠正，重押（纠正响应协议） |
| 押注问 | 纠正（结构性：触及前提/价值排序） | 证伪回退：先回放押注开采纠正文本（纠正措辞 = 浓度最高的沉积物），再对相邻空白采集 |
| 采集问 | 任何回答 | 必跟回放押注：200–300 字压缩，猜测必标注——只有对方说过的算对方的 |

- **节律双锁**：两个采集问之间必须隔一个回放押注；回放之后缺省动作是押注，
  采集须指名地图空白才能发起（「我地图的哪块是空的」）。
- **越权 override**（无视相位）：承诺度满（道层取舍，答案将进对齐快照条款者）
  → 强制带代价二选一（假对齐检验）；带宽耗竭 → 禁开新采集问（回忆是最贵
  任务），只许识别任务，并评估收口。
- **自校准**（阈值数字 = 先验待校准，非实测常数）：存活率趋势升 → 押注占比
  上调；近 4 注存活 <2 → 回退采集并指名回退到哪个前沿；出现重建级纠正 →
  自查哪层采集被跳过，补采并记判例候选。
- **停止条件**：最大强度的押注不再失败——能从对方一句话重推全貌且对方认可 =
  终局押注结算（即本 skill 既有停止条件，引擎不另设终点）。
- **失效条件**：存活率高但终局重推失败（假收敛）→ 代理指标（押注存活率）
  证伪，引擎降级为节律骨架（采集-回放-押注交替保留），选型回归判断。

### 追问循环

问 → 对方回应 → 三类处理（问的选型与节律归「双态引擎」管辖；回应分类沿用本节三分类——引擎主循环表的「证实/纠正（局部/结构性）」即本节的证实/纠正，「拨开」是引擎表外情形，由本节降级规则处理）：

- **证实**：写入对齐快照，推进到下一个最大不确定性；
- **纠正**：**纠正响应协议**——保留已确认结构，用新答案重推，主动检查哪些
  下游确认项需要重新问，禁推倒重来；
- **拨开**（对方不接这个问题）：问题本身错层或过早——降级到提案模式或换层，
  不原样重问。

### 问题分层路由

| 缺口类型 | 问题形状 | 时机 |
|---|---|---|
| 道层 | "A 和 B 只能保一个，你保哪个？"（二选一必须真实、带代价） | 先 |
| 法层 | "这两个目标冲突时，先牺牲哪个指标？" | 中 |
| 术层 | 默认挂起，仅当阻塞当前决策才问 | 后 |

多选题优先（给对方结构化的取舍面，而非开放填空——采集/押注的形态选型归
「双态引擎」管辖，本条适用于押注/取舍题）；内容聚焦 purpose /
constraints / success criteria。

### 方案探索协议（双轨）

> 开创性档触发时，本节「主轨 + 挑战轨」候选生成段由 references/frontier-protocol.md 接管（本节的信息隔离/删除测试/未采纳必录三纪律被其吸收复用）；对照表由选择矩阵替代，合并纪律与同步纪律继续适用。

**主轨**（本 agent）：

- 2-3 个方案各带取舍 + 明确推荐 + 推荐理由（押注：推荐错误泄露的偏好信息
  同样值钱）；
- YAGNI ruthless——每个方案先删非必要特性，再谈取舍；
- 既有代码库跟随既有模式，不做无关重构。

**挑战轨**（方案挑战者 = 独立第二生成源，堵主轨候选集盲区）：

- **派遣时机**：道层收口后、主轨方案探索动手前——L 级 = 追问循环中目标重推
  与道层条款已获对方认可、进入方案探索前；轻量档 = 重述被确认后。目标未钉死
  不派（道层 4：模糊目标谈方案 = 把目标冻死在实现里）；澄清交互期是天然后台
  窗口，派遣不占关键路径。**M 级子档未定前一律按 ML 派遣**（拿不准升级）；
  拍板 MS 时对照表已产出则照常展示。
- **信息隔离**（机制核心）：挑战者输入 = 目标重推 + 道层条款（L 级快照产物；
  轻量档无此产物则该槽填「无——轻量档未澄清」）+ 约束 + 仓库访问权；
  **刻意不给**主轨候选方案与推荐倾向——它必须独立生成，不是评审主案。
- **挑战者产出**（与主轨同构才可对照）：1-2 个候选方案各带取舍 + 它的推荐
  + 关键前提 + 被否决的非常规路线及否决理由。
- **对照表**（主轨产，方案确认停止点的输入）——收敛点（双轨一致 = 强信号，
  直接采纳）/ 分歧点（每条 = 一个决策项：双方取舍 + 主轨推荐 + 置信度）/
  借鉴点（挑战案哪些机制被吸入主案 + 理由）；**未采纳的挑战点必须列出并给
  理由**——对照表即审计，防 cherry-pick。行格式：

  `| 类 | 点位 | 挑战案内容 | 主案内容 | 裁定（采纳/借鉴/否决+理由） |`
- **合并纪律**（防缝合怪）：合并 = 一个主架构 + 借机制，不取平均；合并后方案
  重述前提清单。合并/包含类结构声明（「A 吞并 B」「X ⊆ Y」）必须附逐组件核对表，未附不呈递（漏斗出口的对应核验由 references/frontier-protocol.md §融合审查承载）。
- **同步纪律**：方案确认前挑战者必须已归队；未归 → 显式申报「方案挑战者尚未
  返回结果。选项：①等它归队后补对照表再确认；②按单轨提案确认（对照表
  作废）。」由用户裁定，禁静默降级；挑战者对目标的解读与快照分歧 = 残留
  模糊性信号——回追问循环，不定方案。
  勘探派遣（frontier-protocol.md 各派遣）同守本条同步纪律。
- **出口** = 现有方案确认停止点（不新增停止点）；对照结果记入快照
  「开放决策点+方案选定记录」段，被淘汰路线带理由进挂起清单。

#### 挑战者派遣 prompt 骨架

派遣席位按 caliber §动态组合 2b「方案独立生成」行取链——该行已按任务域
分叉（工程域 / 理论域），链内容以 caliber 表为单一真源，本节不复制。
任务域判定（派遣前一行自问）：目标产物是概念结构（理论框架/方法论/
分类体系/立场文件）→ 理论域；产物是工程制品（代码/配置/系统/操作流程）
或拿不准 → 工程域（默认不换装，防立场膨胀）。fresh 零参与上下文即独立性
载体；后台运行。prompt 按此填槽：

```
你是方案挑战者。任务：对下述已澄清目标**独立**给出方案（理论域任务时
读作「候选框架/主张结构」，下同）。你不知道也不需要知道任何其他方案
——你的价值在于不受既有思路锚定。

**思考角度纪律**（与主轨刻意错位，必须遵守）——按任务域二选一填入，
另一份整段删除不注入：

【工程域】
- 不从现状顺推，从约束与失败形状反推——先问「这个目标绝不能接受的结果
  是什么」，再倒推方案必须满足什么；
- 每个候选方案做一次删除测试：删掉它的某个组成部分，目标是否仍达成
  （能删则原方案有赘肉）；
- 至少认真考虑一条反直觉/非常规路线；最终不推荐也要给否决理由。

【理论域】（产物为概念结构时使用：理论框架/方法论/分类体系/立场文件）
- 可证伪性挑战：对目标隐含的每条核心主张，给出「什么观察或结果会杀死
  它」——说不出杀伤条件的主张是教条，不是方案；
- 另类生成机制：对同一现象构造一个机制不同的竞争解释或框架——哪怕
  最终不推荐，也要给否决理由；
- 范畴/层级审计：检查概念是否跨层混用（把统计描述当机制断言、把操作
  规程当道层原则），指出具体错位点；
- 承重前提审计：列出每个候选框架的承重前提，标明抽掉哪一条会塌；
- 失效条件先行：每个候选框架自带失效条件（什么情况下它不该被用）——
  无失效条件的提案视为未完成。

目标重推：{GOAL}
道层条款（价值排序/不可妥协项/失败的形状）：{TAO_TERMS}
约束：{CONSTRAINTS}

产出（逐条）：
1. 1-2 个候选方案，各带：核心思路、取舍（得什么/舍什么）、关键前提；
2. 你的推荐 + 推荐理由；
3. 被你否决的最有价值的非常规路线 + 否决理由（若与常规做法完全一致
   而未留下任何被否决路线，视为未完成）。

可读仓库核实事实；不写任何文件。
```

### 范围标记与分解

请求横跨多个独立子系统 → 先标记、先分解，不在未分解的大项目上消耗追问；
每个子任务独立走 快照→plan 周期。

### 节奏与降级

对方连续短答、只回"对/行/可以" = 审讯化警报：切换**提案模式**（出一版完整
假设让对方标注增删，而非继续问）。对方深度介入（反驳/追问/修正你）= 对齐
正在发生，保持。

### 假对齐检验

对方顺着说"是"是最危险的信号。道层问题必须让选择真实化——二选一、排序、
带代价的取舍，让模糊的 yes 无法蒙混。对方在两个都不喜欢的选项里被迫挑一个
时暴露的信息，比十个开放问答都多。

### 停止点工艺四条（caliber 融合条款）

1. **问必显态推广**——停止点问题默认押注形态（附推荐答案+置信度）；承诺度满的取舍强制带代价二选一（双态引擎越权条款）；
2. **纠正响应协议**——被纠正时保留已确认结构、用新机制重推、主动检查哪些
   下游确认项需重问，禁推倒重来（机制本体与追问循环细则见 §追问循环，本条
   为四条索引位）；
3. **前提清单交付**——方案确认时显式列出「本方案假设了什么为真」作为独立
   交付物供攻击；
4. **挂起清单**——已否决项带时间戳入档，最多温和复活一次，不自发重提
   （与 caliber 铁律 5 重访触发器配对：触发器管「暂不决定」，挂起清单管
   「已否决」）。

附注：决策延迟分布（瞬时决策=已定居价值勿重提，长斟酌=真开放供选项）为
停止点节奏判定辅助，不占四条位。

## 反模式速查

共十二条：

- **审讯化**：连续正面追问价值排序惹人烦 → 藏问于提案与回放：锚定显式成注可证伪，两采集之间必隔回放（节律双锁）。
- **问卷轰炸**：一次抛多个问题 → 一次一问，绝不例外。
- **押注无注**：该押注时裸问"你想要什么？" → 押注必附建议答案，把思考成本留给自己。
- **恋战不收口**：共同理解已达成还继续问 → 用重推检验，能重推就收口。
- **假对齐**：全 yes 通过 → 道层问题真实化（二选一带代价）。
- **越层深挖**：目标还模糊就问实现细节 → 术层默认挂起。
- **查问倒置**：把环境里可查的事实拿去问对方 → 先查后问，对方只答决策。
- **隐性锚定**：开放问里夹带选项清单或暗示 → 锚定要么显化成押注，要么剥掉
  重问；「挂着选项的开放问」是两者最差组合。
- **模式鞭打**：每轮在采集/押注间来回跳 → 节律双锁（采集后必回放；采集须
  指名空白）。
- **采集成瘾**：开放问永不失败、手感好，但地图从未被测 → 连续多轮无押注 =
  引擎熄火，强制下注。
- **太简单不需要批准**（"This is too simple to need a design"）→ 简单意味着
  短设计，不是无设计（Simple means a short design, not no design）。
- **贴标签跳步骤**（"I'll call it bounded and skip the spec"）→ 伸手拿标签
  跳过工作本身就是疑虑——走更重档（Reaching for a label to skip work IS the
  doubt — take the heavier path）。

1. **触发信号**——四类必记：对方纠正且替换了机制、擦边事件（差点犯的错）、
   押注被证伪、假对齐被戳穿（全 yes 后目标翻车）；失败权重高于成功
   （不对称写入）。
2. **即时登记**——高密度轮次当场标记候选（一句话即可），会话收尾前成文；
   禁止事后凭记忆重建（遗漏集中在最密的轮次）。
3. **成文**——五要素：情境 → 错误 → 机制 → 规则 → 失效条件。
4. **分辨率裁决**——先检索既有判例：情境与机制同构 → 合并；机制不同 →
   新条目。库膨胀成复读 = 沉淀失败。
5. **压缩与复活**——超阈值（约 20 条）压缩进本文件法层并全文备份；每条带
   最后验证时间，长期未验证者降权。
