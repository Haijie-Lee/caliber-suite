# frontier-protocol — 开创性档方案空间勘探协议

> 用途：deep-probe 开创性档的机制细目（SKILL.md 档位协议的展开件）。
> 本协议吸收双轨方案探索的三条纪律：信息隔离、删除测试、未采纳必录。
> 出口 = 现有方案确认停止点，**不新增停止点**。
> 适用：ML/L 级；MS/S 级不开本档（剂量随级缩放）。

## 定位与触发判定

开创性档是方案探索的第三档（单轨 → 双轨 → 空间勘探-漏斗），服务突破性/原创性场景：模型先验边界是瓶颈，去锚定式脑暴不够，需要外部知识扩空间。核心诊断：调研若只做过滤器，产出只是「模型想象得到的方案中证据最足的几个」——调研必须允许改写空间；成本收益比值排序会系统性淘汰高方差高上限路线——入选必须给高上限路线留席。

判定信号三型（任一命中即触发本档评估）：

- a) 需求明示原创/突破（用户原话含「原创」「突破」「前所未有」类意图）；
- b) 一跳先例检查无已知解（模型知识 + ≤1 轻检索后仍无成熟解法指向）；
- c) 常规路线被约束排除（约束条件把已知解法全部排除）。

判定成本封顶 = 一次一跳先例检查；禁完整调研（调研属 §调研双环，不是判定工具）。

判定留痕（义务）：一行证据「查过哪些已知路线、为何排除」写入对齐快照「开放决策点+方案选定记录」段。

判定权：判定默认 agent 自动裁定（判据附证据：查过哪些已知路线、为何排除），用户可在任务开始时前置声明覆盖，声明优先。

判定输出三值：开档 / 常规档 / **挂起探索**——关键前提的证实成本高于本轮探索本身、或在等外部信号时，挂起是合法输出；挂起必须带重访触发器（成熟条件或信号，指向 §时间维），无触发器的挂起 = 丢弃。挂起判定同样留痕。

假阳性出口：判定证据不足 → 按常规档（双轨/单轨）处理——「开创性」标签不得成为跳流程的后门（deep-probe 反模式「贴标签跳步骤」的反向形态，同样禁止）。

适用级别：ML/L；判定命中时任务定级低于 ML → 触发 caliber 执行中复量升级评估（低估即升级条款）。

## 道层前置（顺序纪律）

可能性空间工作必须在道层收口后开始：价值排序/不可妥协项/失败的形状是「方案价值」的定义来源——没有道层条款就没有排序依据。模糊目标不开勘探（deep-probe 道层 4：模糊目标谈方案 = 把未定型的目标冻死在实现里）。

## 可能性空间图（空间 schema）

结构 = 因果链干预点 × 机制族：横轴列干预点（在因果链的哪一环下手），纵轴列机制族（同一族 = 同一干预机制的参数变化；不同族 = 干预机制本体不同）。功能变体不构成新格。

每格字段（一行一格）：核心想法（一句话）+ 关键未知（该格成立与否取决于什么）。

未知登记簿：会翻盘的关键未知逐条列出，每条派生一个调研 query（环 1 的检索输入，见 §调研双环）。

产出者 = 2-3 个独立派遣角度错位、信息隔离（席位 = 方案独立生成行，fresh 零参与）；三视角指定分工：

- 视角 A 失败形状反推：先问「这个目标绝不能接受的结果是什么」，倒推必须满足什么；
- 视角 B 约束反推：从不可妥协项出发枚举可行干预点；
- 视角 C 跨域类比：找相邻领域对同一因果链的干预机制。
- 派遣取舍（2 派遣时）：A + C，B 约束反推由环 1 调研补位；3 派遣时三视角全上。

成本封顶 ≤3 派遣（见 §成本封顶总表）。

## 调研双环

环 1【空间扩张】：席位 = researcher 行；以空间图与未知登记簿为检索式；产出**允许改写空间图**（新增机制族/合并同族/证伪剔除）——只过滤不扩张 = 调研降级为过滤器，禁止；多源交叉验证，关键事实带来源 + 日期。

环 2【前提证实】：深入展开完成后，各方案的翻盘级前提逐条补证据；前提证据状态三值：已证实（带四要素）/ 未证实 / 证伪。

两环合计 ≤2+2 派遣（见 §成本封顶总表）。

证据源顺序纪律：宿主契约/平台机制类断言的扫描顺序 = ①用户级实证档案（`~/.zcode/memory/` 等 memory/learnings 档案，含日期与证伪记录）→ ②官方文档 → ③生产源码 → ④外部检索；文档是通用句、档案是事件级实证，冲突时以档案为权威。

## 证据口径审计

排序（§组合式入选）之前，由证据口径审计席对可行性/价值断言做四要素核对：来源/日期/测量条件/口径。席位链 = `evidence-auditor` → `exec-reviewer` → `general-purpose`（取首个在场者）。

不过审断言不得参与排序；标注「未证实」的断言可展示但必须显式标注。审计 = 1 派遣（见 §成本封顶总表）。

## 组合式入选（安全/平衡/登月三席）

双轴矩阵：横轴 = 证据支撑可行性（过审证据的强度），纵轴 = 对道层价值的贡献 + 上限（区间估计；**禁点估计比值排序**——比值排序会系统性淘汰高方差高上限路线，即突破性路线本身）。

三席定义：

- 安全席 = 证据支撑可行性最高的机制族；
- 平衡席 = 双轴中位的机制族；
- 登月席 = 上限最高的机制族，无论可行性分。

机制族去重：三席不得来自同一机制族。上限 3 席、可少于 3；全图机制族不足时走 §降级与中止出口。

入选语义 = **阶段化承诺**，不是全押：每席输出 = 当前注（本批投入范围）+ 加注触发器（什么信号到达即追加投入）+ 弃注条件（放弃判据的活体形态——方案存活期间持续可弃，不是死后才重审）。登月席尤其不得一次性全押：高方差用时间分批化解（D10），不用保送掩盖。

## 深入展开（同构模板）

每方案一派遣、信息隔离（不给其他方案内容——与挑战者信息隔离同律）。写权限边界：只许创建编排者钉死路径的新文件，不动仓库既有文件。

同构模板（固定 7 节，顺序与节名逐字；与主轨同构才可对照）：

1. 核心论点
2. 机制
3. 前提清单（每条带证据状态：已证实/未证实/证伪）
4. 失败形状
5. 最便宜的证伪实验
6. 放弃判据（kill criteria：出现什么条件时放弃本方案）
7. 成本收益区间（区间值 + 不确定性幅度；禁点估计）

删除测试（继承挑战者纪律）：每方案任删一组成部分，回答目标是否仍达成——能删则赘肉，结论记入该方案第 2 节。

展开派遣数 = 入选席数（≤3，见 §成本封顶总表）。

## 融合审查（漏斗 exit gate）

深入展开与环 2 之后、选择矩阵呈递方案确认停止点之前，由独立审查席对勘探产物与编排者综合做一轮审查。机制定位 = 漏斗的 exit gate（plan-forge 工序 3.5 的方案探索对应物）——收敛性判据与信息隔离覆盖不了两类盲区：①option 文档的证据标注卫生（展开席自标自证、无人核验）；②编排者综合（选择矩阵 + 推荐 + 结构声明）——全漏斗唯一未经对抗审查的产物，而它恰是唯一呈给用户的产物。经验全文见 docs/learnings/2026-10-15-fusion-review-seat-lessons.md。

席位 = 1 派遣（强制，开创性档全程派遣最少时亦不得折叠——折叠此席 = 盲区直达停止点），席位链见 caliber §动态组合 2b「方案勘探融合审查」行（`plan-reviewer` → `general-purpose`）；fresh 零参与（未参加空间映射/调研/展开任一环节）。输入 = 空间图 + option 文档目录 + 编排者起草的选择矩阵与推荐 + 道层条款。

职责四项（逐项输出；逐项零发现合法，但须留「查了什么」一句）：

1. **证据卫生**：option 文档前提清单的证据状态标注 vs 现实逐条核对——宿主契约/平台机制类断言的证据扫描源必须含用户级实证档案（memory/learnings）、官方文档、生产源码；**已证伪误标「未证实」= P1**。
2. **结构声明核查**：编排者综合中的每个结构断言（包含/嵌套/等价/互斥/吞并）逐组件核对——引不到逐组件证据的不成立。
3. **融合评估**：入选方案间是否存在优于任何单选的组合（存在则给逐组件清单）；未选必录理由诚实性复审（防 cherry-pick）。
4. **推荐裁定**：维持 / 修改 / 推翻编排者推荐，各带理由。

审查产出追加进 `<项目根>/.caliber/explorations/`（与空间图同目录）；修正落点 = 选择矩阵与推荐（编排者执行），证据标注修正回写 option 文档（带回写日期标注，不改方案设计本体）。出口不变 = 方案确认停止点（修正后的矩阵 + 审查报告一并呈递），不新增停止点。

## 选择矩阵（方案确认停止点输入）

行 = 价值贴合 / 可行性证据 / 成本区间 / 风险 / 突破上限 / 放弃判据 / **价值时间曲线**（一次性收益 vs 复利型，M5）/ **先验生成率**（D1：该路线单位时间产出多少可迁移轨迹先验）/ **决策可逆窗口**（不可逆点何时到来、过期成本多大）；列 = 各入选方案。

编排者自律：呈递的选择矩阵与推荐中，每个结构声明（包含/嵌套/等价/互斥/吞并）必须附逐组件核对表，未附 = 融合审查席打回。

未选必录理由（对照表即审计，防 cherry-pick）。用户选定 → 记入对齐快照「开放决策点+方案选定记录」段（含选择矩阵结果：选定案 / 未选案 + 理由 + 放弃判据）。

## 产物落点

- 空间图/调研证据/option 文档 → `<项目根>/.caliber/explorations/`（过程件；`.caliber/` 首建规则同 caliber Step 1.5）；
- 选定方案内容 → 迁入 plan 对齐快照节与正文；
- 选定与被否记录 → `docs/adr/ADR-NNNN-<slug>.md`（含被否方案与重审条件；重审触发器 = 选定方案放弃判据被触发）；
- 未选方案 → 挂起清单（带时间戳 + **行权触发器**〔什么信号到达即复活评估〕+ 该方案第 5 节的最便宜证伪实验设计——证伪实验设计了却不随挂 = 挂起即遗忘；温和复活上限一次，deep-probe 停止点工艺第 4 条）。

## 时间维（重探索触发器）

空间图会过期：新轨迹先验持续到达（D1）、残差热点随执行累积（M6）、不回灌即衰减（D6）。重探索的时机判断不得寄生于人类记忆（D12：触发时机感必须外化）——以下三个触发器任一命中即启动空间复勘（重跑 §可能性空间图，后续环节按需）：

1. **空间图半衰期**：执行期产出的新知足以改写 ≥1 个空间格的「关键未知」→ 重跑空间映射；
2. **传感器接入**：M2 摩擦 / 静默传感器在执行期持续累积且方向一致 → 空间复勘，不必等放弃判据触发（放弃判据重审是死后触发器，本器管活体）；
3. **里程碑锚定复查**：选定方案到达预设里程碑或时间盒 → 对照空间图复查一次（即使前两器未命中）。

触发留痕（义务）：哪个触发器、什么证据、复勘结论（维持 / 改写空间图 / 转 §降级与中止出口③），记 ADR 或挂起清单对应条目。

挂账（重提条件 = 触发器三件套实战跑出「单遍不够用」的判例）：①迭代回路——环 2 证伪后带新证据回空间映射的受控回路（迭代上限未定，会在派遣封顶上乘系数——本挂账落地时按届时封顶乘）；②探索×执行时间形态枚举（并行双轨 / 延迟决策）。

## 降级与中止出口

① 先例检查（判定步）发现成熟解 → 退回常规档（双轨/单轨）；
② 机制族 <2（空间图不出两个不同干预机制）→ 伪开创性 → 退双轨标准档；
③ 调研证实全族不可行 → 方案确认停止点带证据上报（可能改需求方向）。

任一出口触发都须留一行证据（哪个信号、指向哪个出口）。
