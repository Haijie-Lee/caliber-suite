# deep-probe 判例库

格式：情境 → 错误 → 机制 → 规则 → 失效条件。失效条件是灵魂——没有失效条件的经验是教条。

## 判例 0：caliber 吸收映射（设计推导，非实战）

- **情境**：caliber 体系自研化（2026-09-20，用户裁定 L 级任务），deep-probe 承接既有澄清工艺资产、替换外部功能依赖——有机融合非简单替换，资产逐项裁定处置。
- **推导**：资产逐项处置映射表（保留/改造/不纳入逐条裁定）：

  | 资产 | 处置 | 落点 |
  |---|---|---|
  | 三路径分类（bounded/architectural/spike） | 不纳入——定级外置，caliber Step 1 为唯一权威 | — |
  | HARD-GATE（方案批准前不动手） | caliber 铁律同构复述 | caliber 停止点工艺（方案确认 **停**） |
  | 一次一问 + 多选题优先 | 保留入法层 | SKILL.md 问题分层路由 |
  | 方案探索（2-3 方案各带取舍+推荐+理由、YAGNI、跟随既有模式） | 注入 | SKILL.md §方案探索协议 |
  | 范围标记与分解 | 注入 | SKILL.md §范围标记与分解 |
  | 分段呈现（chunked presentation） | plan 逐条裁定等价物替代 | plan-drafting 六道锻造（契约矩阵/验证内建） |
  | spec 自审门 | ritual 等价物替代 | plan-review-ritual 对抗审查 + plan-forge 工序 3 |
  | 视觉伴生 | 适配：纪律保留、机制改指平台浏览器能力 | SKILL.md §视觉伴生 annex |

- **增量**：方案探索协议、范围标记与分解、视觉伴生 annex、Red Flags 精选 2 条（太简单不需要批准/贴标签跳步骤）为注入增量；停止点工艺四条（问必带注/纠正响应协议/前提清单交付/挂起清单）为 caliber 侧融合升级。
- **状态**：首个真实 L 级澄清任务判例优先回流。
